### Building Footprint Extraction from Aerial Images

[Repository](https://github.com/sonday205/computer_vision2)

A computer vision project for extracting building footprints from aerial imagery.

- Compared K-Means, Otsu thresholding, Linear SVM, and U-Net on 512x512 image patches from the Inria Aerial Image Labeling Dataset.
- Built preprocessing, training, evaluation, and reporting pipeline with CLAHE, RGB/LAB/HSV pixel features, morphology cleanup, IoU, Dice/F1, Precision, Recall, building count, and area error.
- Tuned U-Net threshold to 0.40 and achieved Dice 0.665, IoU 0.544, Precision 0.698, and 5.26% area error on 300 test patches.
- Packaged a Streamlit inference demo with mask prediction and overlay visualization.

Tech stack: Python, PyTorch, OpenCV, scikit-learn, NumPy, pandas, Matplotlib, Streamlit, Kaggle.
